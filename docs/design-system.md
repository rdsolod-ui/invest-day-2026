# Дизайн и архитектура

Решение от 10.09.2026: одна история из двенадцати сцен. Визуальная основа — реальный парк, его аттракционы и масштаб территории. Источники фотографий и контрольные суммы перечислены в assets.json.

## Стек

Astro 7.3.2, TypeScript, обычный CSS, SVG. Статическая сборка с базовым путём `/invest-day-2026`. Компоненты формируются при сборке; React, backend и база данных не требуются. Версии закреплены package-lock.json. Node 24 используется для воспроизводимой сборки.

Графики и таблицы используют `src/data/metrics.json`. Статусы и ссылки на источники — `sources.json`. Расчёт входящего потока не превращается в факт, старые планы не выдаются за достигнутые результаты. Показатели OPEX и результата от продаж независимы до уточнения состава строк.

## Визуальное решение

Три направления сведены в одну систему: дневной городской парк для основной версии; вечерний синий для тёмной темы; чистые поверхности инвестиционного отчёта для финансов. См. moodboard.html.

Палитра: фон #F3F7FB, текст #102B46, действие #1466B8, бренд #3EBDE6, поверхности #FFFFFF, сравнение #607D98. Тёмная: фон #091A30, панели #112B48, текст #F4F8FC, пояснения #B9CBDD, акцент #73C9FF. Логотип сохранён оригинальным.

Manrope — заголовки и числа, Golos Text — основной текст и подписи. Локальные variable WOFF2, кириллица, ₽, числовые табличные знаки. Лицензии OFL рядом с файлами. Заголовки без курсива, большие интервалы, независимые композиции для разных задач.

Две колонки для визуального повествования; четыре/две колонки для масштаба; вертикальная шкала причин; парные столбцы для фактических сравнений; параллельные годы для переноса целей. Mobile 320px сохраняет весь текст. Графики SVG читаемы без hover, таблицы раскрываются как дополнение.

## Motion

Характер: спокойный деловой. 160 мс обратная связь, 320 мс переход сцены, 420 мс появление, 650 мс рисование стрелки переноса. Кривая cubic-bezier(.2,0,0,1). Основное движение — сцена; вторичное — стрелка; фоновый слой — статичная траектория над фото. Фон сознательно оставлен неподвижным для комфорта при чтении финансов.

Все цифры сразу итоговые: анимация меняет появление и соединение, не значение. При reduced motion перемещения выключены. Элементы никогда не спрятаны исходным CSS: ошибка JS не уничтожает содержание. Нет scroll hijacking и autoplay.

## Презентация

Кнопка «Начать показ» включает пошаговый просмотр. ←/→, ↑/↓, PageUp/PageDown, Home/End работают только в режиме показа. Escape возвращает чтение. Функция Fullscreen включается отдельно, тема сохраняется. Из любой сцены можно открыть источник, выйти из показа и читать пояснения.

В маленьком окне естественный скролл остаётся доступным. Проверка эмуляцией не заменяет проверку реального проектора и физического устройства.
