# Инвест День 2026 · Парк Сказка

Одностраничная презентация: трансформация парка, продукт, маркетинг, инвестиции и результаты. 23 сцены 16:9, три спикера и модератор. Девять сцен CMO: география Москвы/МО, новые аттракционы, Night Riders, CJM, воронка ParkOps, расходы, CPS/ROMI, кросс-продажи и планы. Светлая/тёмная/системная темы, анимация с отключением движения.

Сайт: [marketing.parkskazka.ru/invest-day-2026](https://marketing.parkskazka.ru/invest-day-2026/).

## Сборка

Node.js 24, npm. Версии закреплены lockfile.

```sh
npm ci
npm test
npm run build
npm run preview
```

В dev/preview используйте путь `/invest-day-2026/`. `dist/` — готовый автономный статический артефакт для Nginx. `npm run build` проверяет структуру, локальные ресурсы и отсутствие служебных данных в HTML, затем создаёт SHA-256-манифест.

## Данные и дизайн

- `src/data/metrics.json` — единый набор значений и периодов;
- `src/data/sources.json` — происхождение и статусы;
- `docs/design-system.md` — стек, темы, типографика и motion;
- `docs/moodboard.html` — визуальное направление, открывается локально;
- `docs/assets.json` — источники фотографий;
- `docs/release.md` — публикация и откат.

Документы исходной переписки и персональные контакты в репозиторий не включены. Презентационные данные переданы заказчиком; исходные бухгалтерские документы отдельно не проверялись. Статусы оценки и плана сохранены на экранах. Происхождение и подробные методические пояснения сохранены в данных и документации репозитория. Плановые показатели обозначены как целевые ориентиры.

## Управление

«Начать показ» включает отдельные сцены. Стрелки, PageUp/PageDown, Home/End — переходы; Escape — выход. Полноэкранный режим включается отдельной кнопкой. Каждая сцена масштабируется целиком в формате 16:9. H (Р) скрывает и возвращает панель управления. На телефоне обычный режим чтения перестраивает контент вертикально. Ссылок на источники в интерфейсе нет.

Исторический график и календарь переключают вехи в цикле. Выбор вехи мышью, клавиатурой или касанием закрепляет подсказку и ставит цикл на паузу. Круглая кнопка продолжает анимацию. Общая кнопка движения и системная настройка reduced motion останавливают анимации.

Для резервного показа разместите `dist` в папке `invest-day-2026` локального HTTP-сервера. Внешние CDN и API не требуются. Печатный CSS доступен через системную печать браузера; это не отдельный PDF-экспорт.
