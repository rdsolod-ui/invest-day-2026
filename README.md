# Инвест День 2026 · Парк Сказка

Одностраничная презентация: продукт, трансформация, инвестиции, результаты и целевые ориентиры. Двенадцать сцен, светлая/тёмная/системная темы и режим выступления.

Сайт: [marketing.parkskazka.ru/invest-day-2026](https://marketing.parkskazka.ru/invest-day-2026/).

## Сборка

Node.js 24, npm. Версии закреплены lockfile.

```sh
npm ci
npm test
npm run build
npm run preview
```

В dev/preview используйте путь `/invest-day-2026/`. `dist/` — готовый автономный статический артефакт для Nginx. `npm run build` проверяет структуру, локальные ресурсы и отсутствие служебных данных в HTML, затем создаёт SHA-256-манифест.

## Данные и дизайн

- `src/data/metrics.json` — единый набор значений и периодов;
- `src/data/sources.json` — происхождение и статусы;
- `docs/design-system.md` — стек, темы, типографика и motion;
- `docs/moodboard.html` — визуальное направление, открывается локально;
- `docs/assets.json` — источники фотографий;
- `docs/release.md` — публикация и откат.

Документы исходной переписки и персональные контакты в репозиторий не включены. Презентационные данные переданы заказчиком; исходные бухгалтерские документы отдельно не проверялись. Уточнения методики и статуса показателей находятся рядом с соответствующими разделами. Плановые показатели обозначены как целевые ориентиры.

## Управление

«Начать показ» включает отдельные сцены. Стрелки, PageUp/PageDown, Home/End — переходы; Escape — выход. Полноэкранный режим включается отдельной кнопкой. При малой высоте доступен обычный скролл. Ссылки на источники открывают пояснения и завершают режим показа.

Для резервного показа разместите `dist` в папке `invest-day-2026` локального HTTP-сервера. Внешние CDN и API не требуются. Печатный CSS доступен через системную печать браузера; это не отдельный PDF-экспорт.
